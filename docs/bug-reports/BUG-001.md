## Description
Registration accepts malformed e-mail addresses.

**Code location:** AuthController::register - 'email' rule has no 'email' validator

## Steps to reproduce
1. POST /api/register with email 'not-an-email' and a valid name/password

## Expected result
422 with an error on 'email'

## Actual result
201 Created, account and token issued

## Detected by
- Postman: Register invalid email format
- JUnit: AuthApiTest.registerRejectsInvalidEmail (5 cases)
- Cypress: auth.cy.ts invalid e-mail

## Suggested fix
Add the 'email' rule to the validator.

## Retest
`FIXED_BUGS=BUG-001` (restart the api container) turns off only this bug.
Re-run the tests listed under *Detected by*: they must pass, and the rest of the regression suite must stay green.
