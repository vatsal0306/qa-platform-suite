## Description
Broken object-level authorization: any user can access any order (IDOR).

**Code location:** OrderController::load - ownership check skipped

## Steps to reproduce
1. Register users A and B
2. A creates an order (id N)
3. As B call GET/PUT/DELETE /api/orders/N and POST /api/orders/N/pay

## Expected result
403 Forbidden

## Actual result
200 - B can read, edit, pay, ship, cancel and delete A's order

## Detected by
- Postman: User B cannot read/update/pay user A order
- JUnit: OrderApiTest.isolationBetweenUsers

## Suggested fix
Compare order.user_id with the authenticated user (or scope the query / use a policy).

## Retest
`FIXED_BUGS=BUG-003` (restart the api container) turns off only this bug.
Re-run the tests listed under *Detected by*: they must pass, and the rest of the regression suite must stay green.
