## Description
Order can be paid more than once (double charge).

**Code location:** OrderController::pay - status guard allows 'paid'

## Steps to reproduce
1. Create an order
2. POST /pay twice

## Expected result
Second call: 409 Conflict, payment_attempts stays 1

## Actual result
Second call 200, payment_attempts = 2

## Detected by
- Postman: Pay again
- JUnit: WorkflowApiTest.cannotPayTwice
- PL/SQL: SINGLE_PAYMENT

## Suggested fix
Allow payment only from status 'created'; make the transition idempotent / use a DB lock.

## Retest
`FIXED_BUGS=BUG-004` (restart the api container) turns off only this bug.
Re-run the tests listed under *Detected by*: they must pass, and the rest of the regression suite must stay green.
