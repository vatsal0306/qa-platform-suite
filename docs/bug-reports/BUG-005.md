## Description
Unpaid order can be shipped.

**Code location:** OrderController::ship - 'created' accepted as a source status

## Steps to reproduce
1. Create an order
2. POST /ship without paying

## Expected result
409 Conflict

## Actual result
200, status shipped, paid_at is null

## Detected by
- Postman: Ship before pay
- JUnit: WorkflowApiTest.cannotShipUnpaid
- PL/SQL: SHIPPED_WAS_PAID

## Suggested fix
Ship only from status 'paid'.
