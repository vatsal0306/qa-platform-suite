# BUG-006: Pagination repeats the last row of the previous page

| Status | Open |

## Description
Pagination repeats the last row of the previous page.

**Code location:** OrderController::index - offset reduced by 1 for page > 1

## Steps to reproduce
1. Create 5 orders
2. GET /api/orders?per_page=2&page=1 then page=2

## Expected result
Pages contain disjoint ids

## Actual result
First row of page 2 equals last row of page 1; the last order is never reachable

## Detected by
- Postman: Pagination page 2 overlap
- JUnit: OrderApiTest.paginationHasNoOverlap
- Cypress: orders.cy.ts pagination

## Suggested fix
offset = (page - 1) * per_page.
