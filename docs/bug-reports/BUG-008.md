## Description
Login reveals whether an e-mail is registered (user enumeration).

**Code location:** AuthController::login - separate 404 branch for unknown e-mail

## Steps to reproduce
1. POST /api/login with an unregistered e-mail

## Expected result
401 'Invalid credentials' (identical to a wrong password)

## Actual result
404 'No account found for this email'

## Detected by
- Postman: Login unknown email
- JUnit: AuthApiTest.loginDoesNotEnumerateUsers
- Cypress: auth.cy.ts same message

## Suggested fix
Return the same status and message for both cases (and add rate limiting).

## Retest
`FIXED_BUGS=BUG-008` (restart the api container) turns off only this bug.
Re-run the tests listed under *Detected by*: they must pass, and the rest of the regression suite must stay green.
