## Description
customer_name longer than 100 chars causes HTTP 500.

**Code location:** OrderController::store - max length rule removed; DB column is VARCHAR(100)

## Steps to reproduce
1. POST /api/orders with a 101-character customer_name

## Expected result
422 validation error

## Actual result
500 Server Error (DB truncation)

## Detected by

- JUnit: OrderApiTest.customerNameLength
- Cypress: 101-char name

## Suggested fix
Validate 'max:100'; never let user input reach the DB unvalidated.
