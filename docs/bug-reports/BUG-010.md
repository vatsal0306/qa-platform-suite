## Description
Shipped orders can be cancelled.

**Code location:** OrderController::cancel - 'shipped' accepted as a source status

## Steps to reproduce
1. Create, pay and ship an order
2. POST /cancel

## Expected result
409 Conflict

## Actual result
200, status cancelled while shipped_at is still set

## Detected by
- Postman: Cancel shipped order
- JUnit: WorkflowApiTest.cannotCancelShipped
- PL/SQL: CANCELLED_NOT_SHIPPED

## Suggested fix
Cancel only from 'created' or 'paid'.
