## Description
Login / register inputs have no accessible labels.

**Code location:** Login.tsx - placeholder used instead of <label>

## Steps to reproduce
1. Open the login page
2. Run axe-core or inspect with a screen reader

## Expected result
Each field has a programmatically associated label

## Actual result
axe rule 'label' fails; placeholders vanish on input

## Detected by
- Cypress: accessibility.cy.ts login page

## Suggested fix
Add <label htmlFor> elements (and autocomplete attributes).

## Retest
UI bugs (BUG-011..BUG-015) are switched off with `VITE_SEEDED_BUGS=false` (rebuild the web container).
