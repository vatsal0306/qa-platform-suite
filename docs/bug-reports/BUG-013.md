## Description
Orders table forces horizontal scrolling on small screens.

**Code location:** OrderList.tsx + styles.css - table min-width 720px without a scroll container

## Steps to reproduce
1. Open the orders list at 375px width

## Expected result
No horizontal page scroll (content reflows or the table scrolls inside its own container)

## Actual result
The whole page scrolls sideways

## Detected by
- Cypress: responsive.cy.ts (4 small viewports)
- Playwright: iPhone / Pixel overflow test

## Suggested fix
Wrap the table in an overflow-x container and drop the fixed min-width on the page.

## Retest
UI bugs (BUG-011..BUG-015) are switched off with `VITE_SEEDED_BUGS=false` (rebuild the web container).
Re-run the tests listed under *Detected by*: they must pass, and the rest of the regression suite must stay green.
