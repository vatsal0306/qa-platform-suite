## Description
'Pay' action is a clickable <div>, not a button.

**Code location:** OrderDetail.tsx - div with onClick

## Steps to reproduce
1. Open a created order
2. Try to reach Pay with the Tab key

## Expected result
Pay is focusable and activates with Enter/Space

## Actual result
Pay cannot be focused; keyboard and screen-reader users cannot pay

## Detected by
- Cypress: workflow.cy.ts Pay is a button

## Suggested fix
Use a <button>.

## Retest
